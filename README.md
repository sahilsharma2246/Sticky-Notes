# Sticky Notes App

A simple sticky notes app built with HTML, CSS, and JavaScript.

## Features
* Add new notes with title and content
* Edit existing notes
* Delete notes
* Responsive design for mobile and desktop
* Notes persist across sessions using localStorage

## Demo
[Live Demo](https://sahilsharma2246.github.io/Sticky-Notes/)

## Installation
1. Clone the repository: `git clone https://github.com/sahilsharma2246/Sticky-Notes.git`
2. Open `index.html` in your browser

## Usage
1. Click the "Add Note" button to create a new note
2. Click on a note to edit its title and content
3. Click the "Delete" button to remove a note

## Tech Stack
* HTML
* CSS
* JavaScript
